# Ева

Помощник администратора образовательного центра «Пиксель» и клуба программирования «Кодология». Ева готовит черновики ответов клиентам и задачи для администратора. Автоматическая отправка клиентам запрещена.

## Состав

| Каталог | Что внутри | Статус |
|---|---|---|
| `panel/` | Закрытая веб-панель «Ева — разбор диалогов» (TypeScript, React, Cloudflare D1, MCP). История перенесена из Sites, HEAD исходника `55e7581`. | Опубликована в Sites |
| `server/` | Python-бот на сервере (`eva`, `eva-vk-admin`). | Будет добавлен после сверки с работающим сервером |
| `docs/` | Состояние проекта и план запуска. | |

Начинать с [docs/PROJECT_STATE.md](docs/PROJECT_STATE.md).

## Правила репозитория

- Никаких секретов, токенов, `eva.env`, баз SQLite/D1 и клиентских переписок.
- Каждое изменение отмечается отдельно: подготовлено, согласовано владельцем, внедрено.
- Исторические архивы не копировать поверх `/opt/eva`.
