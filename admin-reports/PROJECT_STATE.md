# Ева: состояние сервиса отчётов

Срез: 5 ноября 2026, МСК. Этот файл описывает сервис отчётов; он не
заменяет общую документацию по запуску проекта и веб-панели.

| Часть | Что подтверждено |
| --- | --- |
| Сверка оплаты | Установщик подтвердил замену рабочего файла, резервную копию и запуск сервиса. Однозначное сообщение о прошлой оплате добавляет подсказку проверить поступление; спор по счёту — подсказку сверить занятия с планом. Запрос новой ссылки не запускает сверку. |
| Свободные места | Отпечатки функций рабочего файла совпали с патчем, сервис был активен. Процесс имел доступ к локальной сводке AlfaCRM. Число мест берётся только для однозначно найденного ближайшего занятия при свежей сводке и согласованных счётчиках. |
| Промпт и история | Рабочий промпт v4 сохранён. Экспериментальные v5/v5.1 и кандидат на изменение сборки истории в эту версию не входят. |
| Проверка | 34 локальных теста. После установки код проверен отдельно от поведения на живых сообщениях. Доставка и содержание нового отчёта на живой переписке не подтверждались; владелец решил пропустить этот этап. |

Ответы остаются черновиками для администратора. Патчи не меняют получателей,
не создают записи, бронь или платежи в AlfaCRM и не вмешиваются в передачу
Wazzup → AlfaCRM. В репозитории серверные идентификаторы заменены заглушками.

При следующей установке сначала сверить рабочий файл, создать резервную копию
и проверить запуск сервиса. Для отката вернуть рабочий файл из резервной копии
соответствующей установки и проверить сервис после перезапуска. Не заменять
рабочий файл репозиторной копией с заглушками.

Дальше, после обновления лимитов:

1. Поддержать вопросы о местах с предметом или филиалом из предыдущих реплик.
   Проверять однозначность выбора группы на вымышленных примерах.
2. Подключить проверяемую цену одной конкретной услуги из актуального прайса.
3. Улучшить подсказки администратору и затем вернуться к очереди задач и сводке.
