# Почему Ева передаёт обращения старшему

Срез 28.10.2026, только счётчики из базы на сервере (тексты клиентов не выгружались).

## Итог

После новой маршрутизации (с 16.10) доля черновиков выросла с 3–17% до 55–57%. Но настоящих ответов почти нет: из 504 черновиков только 5 готовы как есть. Половина черновиков — шаблонное переспрашивание «Правильно ли я понимаю, ваш вопрос — …?». 44% сообщений не попадают ни в один сценарий. Это предел лексического сопоставления по ключевым словам; без смыслового разбора (LLM) дальше не продвинуться.

## Причины, 908 сообщений с 16.10

| Причина | Сообщений | Что это значит |
|---|---:|---|
| KNOWLEDGE_GAP | 404 | Ни один шаблон не подошёл, черновика нет |
| SCENARIO_CLARIFICATION | 249 | Слабое совпадение, черновик — переспрашивание |
| MISSING_CRM_FACTS | 113 | Нужны данные CRM (оплата, расписание ученика) |
| ATTACHMENT_REVIEW | 84 | Вложение, которое Ева не читает |
| MANDATORY_HANDOFF | 25 | Сценарий всегда идёт старшему |
| MISSING_CUSTOMER_DATA | 16 | Нужно уточнить у клиента |
| MULTI_INTENT_CLARIFICATION | 12 | Несколько вопросов в одном |
| SCENARIO_READY | 5 | Готовый ответ |

Среди 404 сообщений без сценария: 184 из 1–2 слов, из них 140 без букв (эмодзи, стикеры, знаки) и 31 «+». Частых слов (8+ повторов) нет, вопросы разнообразные.

Самые частые сценарии в черновиках: уведомление о домашнем задании (100), пропуск занятия (53), статус оплаты (36).

## Каналы и филиалы

MAX 666, VK 242. Филиал не определён ни у одного сообщения.

## Уведомления администратору

Задачи по одной в VK отправлялись до 15.10 (до 277 в день). С 16.10 новые задачи в этот поток не попадают: код ограничивает его порогом `baseline_inbound_id`, а новые обращения идут в отдельные отчёты `eva-admin-reports` двум получателям. Код этого сервиса в архив не попал; что он реально отправляет, ещё нужно проверить. Все 2 326 задач в базе открыты, командами старшего не пользовались с 02.10.

## Что из этого следует

1. Смысловой разбор через LLM нужен, чтобы ответы стали ответами, а не переспрашиванием.
2. Сообщения без букв, «+» и «спасибо» не должны создавать задачи старшему.
3. Определять филиал по каналу MAX/VK.
4. Проверить `eva-admin-reports`: доходит ли до администратора что-то с 16.10.
