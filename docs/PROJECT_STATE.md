## Решения владельца

- Ответы клиентам только черновики администратору.
- Общие правила и сценарии согласуются с владельцем.
- Анализ правок в панели идёт через чат, без отдельного LLM API.
- Передачу Wazzup → AlfaCRM не менять.
- Скидка многодетным: плоские 10% (ответ владельца 28.10.2026).
- LLM серверного бота: владелец предложил бюджетную «6.1 терра» (28.10.2026); точный идентификатор модели, провайдер и цену ещё нужно подтвердить.
